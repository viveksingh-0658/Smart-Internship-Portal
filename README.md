# Smart Internship & Industry Collaboration Portal

A full-stack internship management platform that connects Students, Companies, and Administrators through a centralized recruitment system.

## Features

### Student Module
- Student Registration & Login
- Browse Available Internships
- Apply for Internships
- Track Application Status

### Company Module
- Company Registration & Login
- Post Internship Opportunities
- View Applications
- Manage Recruitment Process

### Admin Module
- Manage Students and Companies
- Monitor Internship Listings
- Platform Administration

## Tech Stack

### Frontend
- HTML
- CSS
- JavaScript

### Backend
- Node.js
- Express.js

### Database
- MongoDB

### Authentication
- JWT (JSON Web Token)

bash
